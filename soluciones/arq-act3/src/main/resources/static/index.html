Bienvenido

Esta aplicación muestra una página de saludo en cuatro idiomas. La ruta /elegir?idioma=... recoge el parámetro idioma y te redirige a la página correspondiente.

Elige el idioma en el que quieres ver la página:

  • Español
  • Français
  • English
  • Deutsch

Si no eliges un idioma (/elegir) o escribes uno no reconocido, se mostrará la página en inglés.
